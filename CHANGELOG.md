# Changelog

## 0.1.0 — 2026-10-09

First release.

- Drag-and-drop monitor layout with edge snapping.
- Resolution, refresh rate, scale, rotation and enable/disable per monitor.
- Workspace 1–10 to monitor assignment.
- Apply (live session) and Save (managed block in `monitors.lua`).
- Monitor serial numbers are never shown (make + model only).
- Unit tests for the layout logic, run in CI.
